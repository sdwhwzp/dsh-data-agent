这次主要解决升级到 DSH `0.2.0-rc.2` 后，data-agent 因版本限制无法正常启用的问题。

- 适配 DSH `0.2.0-rc.2`，让数据模式和数据库工作台可以正常加载。
- 将 DSH 版本要求放宽为 `>=0.2.0-rc.1`，不再只允许某一个 rc 版本。
- 数据库连接、SQL 查询和分析报告的使用方式保持不变，已有连接配置和自定义预设会保留。

推荐搭配 DSH `0.2.0-rc.2` 使用，这是本版实际完成运行验证的版本。版本范围放宽不代表所有后续版本都已验证。

**安装或升级 Web 插件：**

```sh
dsh plugin --profile web add @yejiming/dsh-data-agent@0.2.2 --registry=https://registry.npmjs.org/
```

安装完成后，退出正在运行的 DSH，重新执行 `dsh web`，再刷新浏览器页面。
