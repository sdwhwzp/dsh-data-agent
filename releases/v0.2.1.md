这次主要解决升级到 DSH `0.2.0-rc.1` 后，data-agent 在插件列表里显示“异常”、无法启用的问题。

- 更新了插件的版本要求，让数据模式能在 DSH `0.2.0-rc.1` 中正常加载。
- 已确认 Web 中的数据模式、数据库工作台入口可以正常显示，也补充了新版界面的兼容测试。
- 这次是兼容性修复，数据库连接、SQL 查询和分析报告的使用方式没有变化。

**版本要求：本版适配 DSH `0.2.0-rc.1`。如果还在使用旧版 DSH，请继续使用与它匹配的旧版插件。**

安装或升级 Web 插件：

```sh
dsh plugin --profile web add @yejiming/dsh-data-agent@0.2.1 --registry=https://registry.npmjs.org/
```

安装后，请退出正在运行的 DSH，重新执行 `dsh web`，再刷新浏览器页面。

发布前已通过类型检查、构建和 444 项测试，另有 3 项外部数据库测试跳过。打包后的插件已完成 SQLite 查询和会话恢复验证，本机 Web 中两个插件组件均正常运行。这次没有连接业务数据库，也没有验证真实模型 API。
